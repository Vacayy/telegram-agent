# AI Debate 기능 구현 계획서

## 1. 기능 개요

### 목적
사용자의 질문에 대해 3명의 AI 페르소나가 **다각도로 심층 토론**을 진행하여, 단일 관점으로는 얻기 어려운 균형 잡힌 인사이트를 제공합니다.

### 사용 방법
```
/ai-debate 비트코인 10만달러 갈까?
```

---

## 2. 토론 구조 (7단계)

기존 3단계(입장→반박→결론)에서 **7단계**로 확장하여 더 깊이 있는 논의를 유도합니다.

```
┌─────────────────────────────────────────────────────────────┐
│  Phase 1: 준비                                               │
├─────────────────────────────────────────────────────────────┤
│  [1] 페르소나 생성 - 주제에 맞는 3명의 전문가 구성            │
│  [2] 정보 수집 (선택) - 웹/X 검색으로 최신 데이터 확보        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Phase 2: 토론 (5라운드)                                     │
├─────────────────────────────────────────────────────────────┤
│  [3] Round 1: 초기 입장 발표                                 │
│      - 각자의 관점에서 주제에 대한 입장 표명                  │
│      - 핵심 논거 제시                                        │
│                              ↓                               │
│  [4] Round 2: 교차 질문                                      │
│      - 다른 참가자의 입장에 대한 질문                        │
│      - 논리적 허점이나 불확실한 부분 지적                    │
│                              ↓                               │
│  [5] Round 3: 반박 및 방어                                   │
│      - 받은 질문에 대한 답변                                 │
│      - 자신의 입장 방어 및 보강                              │
│                              ↓                               │
│  [6] Round 4: 입장 조율                                      │
│      - 다른 의견의 타당한 부분 인정                          │
│      - 필요시 자신의 입장 수정/보완                          │
│      - 공통점 도출 시도                                      │
│                              ↓                               │
│  [7] Round 5: 최종 입장 정리                                 │
│      - 토론을 통해 도달한 최종 결론                          │
│      - 핵심 인사이트 요약                                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Phase 3: 종합                                               │
├─────────────────────────────────────────────────────────────┤
│  [8] 최종 리포트 생성                                        │
│      - 합의점 / 쟁점 / 종합 결론                             │
└─────────────────────────────────────────────────────────────┘
```

## 3. 각 라운드 상세

### Round 1: 초기 입장 발표 (Opening Statements)

**목적**: 각 페르소나가 자신의 관점과 핵심 논거를 명확히 제시

**프롬프트 지침**:
```
당신은 {persona.name}입니다. {persona.description}

질문: {query}

당신의 전문 분야 관점에서:
1. 이 질문에 대한 명확한 입장을 밝히세요
2. 그 입장을 뒷받침하는 핵심 논거 2-3개를 제시하세요
3. 가능하면 데이터나 사례를 인용하세요

형식: 200자 내외로 간결하게
```

**예시 출력**:
```
🐂 낙관론자 (시장 전문가):
"ETF 승인 이후 기관 자금 유입이 가속화되고 있습니다.
BlackRock의 IBIT는 출시 6개월 만에 200억 달러를
돌파했고, 반감기 효과가 본격화되는 하반기에
10만 달러 돌파는 충분히 가능합니다."
```

---

### Round 2: 교차 질문 (Cross-Examination)

**목적**: 다른 참가자의 논리적 허점이나 불확실한 가정을 지적

**프롬프트 지침**:
```
다른 참가자들의 입장을 읽었습니다:
{other_statements}

당신은 {persona.name}입니다.

다른 참가자들의 입장에서:
1. 논리적으로 약한 부분이나 검증되지 않은 가정을 찾으세요
2. 날카롭지만 건설적인 질문을 1-2개 던지세요
3. 단순 반박이 아닌 "왜?", "어떻게?"를 묻는 질문으로

형식: 각 참가자에게 1개씩 질문 (총 2개)
```

**예시 출력**:
```
⚖️ 중립자 → 🐂 낙관론자에게:
"기관 자금 유입이 지속될 것이라는 근거는?
금리 인하 지연 시에도 같은 추세가 유지될까요?"

⚖️ 중립자 → 🐻 비관론자에게:
"규제 리스크를 언급했는데, 구체적으로 어떤 규제가
시장에 가장 큰 영향을 줄 것으로 보시나요?"
```

---

### Round 3: 반박 및 방어 (Rebuttal & Defense)

**목적**: 받은 질문에 답변하고 자신의 입장을 방어/보강

**프롬프트 지침**:
```
당신에게 다음 질문이 제기되었습니다:
{questions_to_me}

당신은 {persona.name}입니다.

1. 각 질문에 구체적으로 답변하세요
2. 필요하면 추가 논거나 데이터로 입장을 보강하세요
3. 상대방의 지적이 타당하다면 인정하되,
   그것이 전체 논지를 흔들지 않는 이유를 설명하세요

형식: 질문당 100자 내외 답변
```

**예시 출력**:
```
🐂 낙관론자의 답변:

Q: 기관 자금 유입 지속 근거?
A: "연기금과 자산운용사의 비트코인 배분은 아직 초기
단계입니다. 피델리티 조사에 따르면 기관의 35%가
추가 배분을 계획하고 있습니다. 금리 인하 지연은
단기 변동성을 높이지만, 장기 수요 기반은 견고합니다."
```

---

### Round 4: 입장 조율 (Position Refinement)

**목적**: 토론을 통해 배운 점을 바탕으로 입장을 수정하거나 보완

**프롬프트 지침**:
```
지금까지의 토론 내용:
{debate_history}

당신은 {persona.name}입니다.

토론을 통해:
1. 다른 참가자의 의견 중 타당하다고 인정할 부분이 있다면?
2. 자신의 초기 입장에서 수정하거나 보완할 부분이 있다면?
3. 세 사람 모두가 동의할 수 있는 공통점은?

중요: 무조건 자기 입장을 고수하지 말고,
건설적인 토론의 결과로 입장이 진화할 수 있습니다.

형식: 150자 내외
```

**예시 출력**:
```
🐂 낙관론자:
"비관론자가 지적한 규제 리스크는 타당합니다.
특히 미국 대선 결과에 따라 변동성이 클 수 있죠.
다만, 10만 달러 도달 자체보다는 '언제'가
불확실한 것이지, 장기적 방향성은 여전히 긍정적입니다.

공통점: 단기 변동성 대비가 필요하다는 데 동의합니다."
```

---

### Round 5: 최종 입장 정리 (Closing Statements)

**목적**: 토론을 통해 도달한 최종 결론과 핵심 인사이트 요약

**프롬프트 지침**:
```
전체 토론 히스토리:
{full_debate_history}

당신은 {persona.name}입니다.

최종 정리:
1. 토론을 통해 도달한 당신의 최종 입장은?
2. 사용자에게 전달하고 싶은 핵심 인사이트 1가지
3. 구체적인 제안이나 행동 지침이 있다면?

형식: 150자 내외, 명확하고 실용적으로
```

**예시 출력**:
```
🐂 낙관론자 최종:
"결론: 10만 달러 도달 가능성 높음, 다만 시기는 불확실

핵심 인사이트: ETF 승인 이후의 기관화 흐름은
2017년 개인 투기와 본질적으로 다릅니다.

제안: 일시에 투자보다 분할 매수로 변동성 대응을 권장합니다."
```

토론 종료 후 AI가 전체 토론을 분석하여 종합 리포트 생성:

```
🎭 AI Debate 결과 리포트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 주제: 비트코인 10만달러 갈까?

👥 참가자
• 🐂 낙관론자 - 암호화폐 시장 전문가
• 🐻 비관론자 - 리스크 분석가
• ⚖️ 중립자 - 퀀트 애널리스트

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🤝 합의점 (모두 동의)
• ETF 승인은 시장 구조를 근본적으로 변화시켰음
• 단기 변동성은 높을 것으로 예상
• 분할 매수 전략이 합리적

• 연내 도달 시점: 낙관론자(Q3), 비관론자(2025년 이후)
• 규제 리스크 심각성: 낙관론자(관리 가능), 비관론자(주요 변수)

📊 종합 결론
10만 달러 도달 가능성은 60-70%로 평가됩니다.
기관 자금 유입이라는 구조적 변화가 뒷받침하나,
거시경제 불확실성과 규제 리스크로 인해

💡 실행 제안
• 분할 매수 전략 (3-6개월에 걸쳐)
• 포트폴리오 비중 5-10% 이내 권장
• 변동성 대비 손절 라인 설정

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⏱️ 토론 시간: 약 2분
💰 예상 비용: $0.02 (Gemini 무료 티어 사용)
```

## 5. 기술 설계

### 5.1 파일 구조

```
src/
├── debate/
│   ├── __init__.py
│   ├── orchestrator.py    # 토론 진행 총괄
│   ├── persona.py         # 페르소나 생성 및 관리
│   ├── round_handler.py   # 각 라운드 처리 로직
│   └── report.py          # 최종 리포트 생성
└── bot.py                 # /ai-debate 명령어 추가
```

### 5.2 핵심 클래스

```python
@dataclass
class Persona:
    id: str                  # "optimist", "skeptic", "neutral"
    name: str                # "낙관론자"
    emoji: str               # "🐂"
    role: str                # "암호화폐 시장 전문가"
    description: str         # 상세 역할 설명
    system_prompt: str       # LLM 시스템 프롬프트

@dataclass
class Statement:
    persona_id: str
    round_number: int
    round_type: str          # "opening", "question", "rebuttal", etc.
    content: str
    timestamp: datetime

@dataclass
class DebateSession:
    id: str
    query: str
    personas: list[Persona]
    statements: list[Statement]
    background_info: Optional[str]  # 웹/X 검색 결과
    status: str              # "preparing", "debating", "completed"

@dataclass
class DebateReport:
    consensus: list[str]     # 합의점
    disputes: list[str]      # 쟁점
    conclusion: str          # 종합 결론
    recommendations: list[str]  # 실행 제안
    stats: dict              # 토론 시간, 비용 등

class DebateOrchestrator:
    async def start_debate(self, query: str, callback) -> DebateReport:
        """토론 시작 및 진행"""

    async def generate_personas(self, query: str) -> list[Persona]:
        """주제에 맞는 페르소나 3명 생성"""

    async def run_round(self, round_type: str) -> list[Statement]:
        """특정 라운드 실행"""

    async def generate_report(self) -> DebateReport:
        """최종 리포트 생성"""
```

### 5.3 병렬 처리

각 라운드 내에서 3명의 페르소나는 **동시에** 응답을 생성합니다:

```python
async def run_round(self, round_type: str) -> list[Statement]:
    tasks = [
        self._get_persona_response(persona, round_type)
        for persona in self.personas
    ]
    statements = await asyncio.gather(*tasks)
    return statements
```

### 5.4 상태 업데이트

각 라운드 시작/완료 시 텔레그램 메시지 업데이트:

```python
async def update_status(self, message: str):
    """텔레그램 메시지 실시간 업데이트"""
    await self.status_msg.edit_text(message, parse_mode="Markdown")
```

업데이트 예시:
```
🎭 AI Debate 진행 중...

✅ Round 1: 입장 발표 완료
✅ Round 2: 교차 질문 완료
🔄 Round 3: 반박 진행 중...
⏳ Round 4: 입장 조율 대기
⏳ Round 5: 최종 정리 대기
```

## 9. 예상 이슈 및 대응

### 이슈 1: 토론이 너무 오래 걸림
**대응**:
- 각 응답 길이 제한 (500자)
- 구조화된 핵심 위주의 토의. 핵심-근거 순의 comment 하도록 유도.
- 병렬 처리로 라운드 시간 최소화
